# アプリコンセプト定義書：Time Capsule Desk

## 1. アプリ名（仮）

**Time Capsule Desk**
（未来から届く手紙と、今日の作業机）

## 2. コアコンセプト

**「未来から届く手紙」×「迷ったらとりあえず机へ」**

- **未来への手紙:** 今やる必要のないことは「手紙」としてポストに投函し、その日が来るまで完全に隠しておく。
- **今日の机:** 届いた手紙を「やる（完了）」「後で（先送り）」「今日キープ（保留）」に仕分け、**今日だけの使い捨て ToDo リスト**を作る。

## 3. 解決する課題とアプローチ

| 課題               | 解決策                                                                                                                         |
| :----------------- | :----------------------------------------------------------------------------------------------------------------------------- |
| **忘却・ノイズ**   | 「未来への手紙」として投函すれば、その日まで視界から消え、必要な時にだけ届く。                                                 |
| **即決の疲れ**     | 朝見て「いつやるか」決めきれなくても、「とりあえず保留（机へ）」で判断を先延ばしできる。                                       |
| **リストの陳腐化** | 机（リスト）にあるタスクは、**翌朝には自動的にポスト（山）に戻る**。これにより、毎日必ず「新鮮なリスト」を作り直すことになる。 |

## 4. ユーザー体験フロー（UX）

アプリの画面は**「上半分：ポスト（Inbox）」**と**「下半分：机（Desk）」**で構成されます。

### Step 0: 投函（Write） - いつでも

- 「あっ、あれやらなきゃ」と思い出したその瞬間に。
- 内容を書き、「いつ思い出させてほしいか（日付）」を指定してボタンを押す。
- **投函したカードは、その場ですぐに画面から消え去る。**
- （今日の日付でない限り、ポストにも机にも表示されない。「未来まで忘れていい」という安心感を得る）

### Step 1: 届く（Morning）

- 過去の自分が書いた「手紙（カード）」が、指定した日付にポストに届く。
- 画面上部にはカードが重なって表示され、一番上の内容だけが見える。

### Step 2: 仕分ける（Triage）

一番上のカードを見て、ボタンまたはスワイプで判断する。

1.  **完了 (Done):**
    - 「もう終わった」「読んだから OK」
    - → **アーカイブ（消滅）**
2.  **先送り (Snooze):**
    - 「今日はやらない」「来週また教えて」
    - → **再び未来への手紙となり、指定日まで隠れる**
3.  **保留 (Keep):** ✨ _Key Feature_
    - 「今日やるかも」「忘れないように出しておこう」「後で判断」
    - → **下半分の「机」エリアに移動し、今日のリストになる**

### Step 3: 過ごす（Day）

- 仕分けが終わると、ポスト（上半分）は空っぽになり、美しい背景が表示される。
- 下半分の「机」には、今日「保留」にしたカードだけが並んでいる。
- これらは通常の ToDo リストとして機能し、終わったらチェックを入れて完了できる。

### Step 4: リセット（Night/Reset）

- もし「机」に残ったまま寝てしまっても大丈夫。
- **翌朝、机に残っていたカードは自動的に「ポスト」に戻される。**
- これによって「やり残しリスト」がゾンビのように溜まるのを防ぎ、毎朝必ず「今日やるか？」を問い直す機会が生まれる。
